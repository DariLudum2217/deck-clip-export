# Deck Clip Export

Плагин для [Decky Loader](https://github.com/SteamDeckHomebrew/decky-loader): экспорт записей Steam Game Recording в стандартный формат MP4 и отправка записей и скриншотов на другие устройства через [LocalSend](https://localsend.org) или [Syncthing](https://syncthing.net). Вся настройка выполняется в игровом режиме, без перехода в режим рабочего стола и использования терминала.

В игровом режиме Steam позволяет поделиться только обрезанным фрагментом записи длительностью меньше минуты; сохранить запись целиком в виде видеофайла можно только в режиме рабочего стола. На диске записи хранятся в виде фрагментов DASH, а не видеофайлов. Плагин экспортирует записи целиком прямо в игровом режиме.

[English version](README.md)

## Возможности

- **Экспорт в MP4.** Фрагменты записи объединяются в стандартный файл `.mp4` без перекодирования, поэтому экспорт выполняется быстро и без потери качества. Видео в формате HEVC помечается для совместимости с устройствами Apple.
- **Обзор скриншотов и записей.** Группировка по дням или общая сетка, настраиваемый размер плиток, фильтры по типу и игре, выделение для групповых действий с контроллера.
- **Два способа отправки.** Можно выбрать подходящий или использовать оба:
  - **LocalSend** передаёт выбранные файлы напрямую на смартфон, планшет или компьютер в той же сети. Устройства-получатели находятся автоматически или добавляются по адресу.
  - **Syncthing** (дополнительно) поддерживает папку синхронизированной с другими устройствами по локальной сети или через интернет. Отправленные файлы поступают автоматически, без подтверждения.

  Облачное хранилище, учётные записи и ограничения по размеру файлов отсутствуют.
- **Управление хранилищем.** Собственные копии плагина (экспортированные файлы MP4 и копии для отправки через Syncthing) можно удалять вручную или автоматически после отправки. Оригинальные скриншоты и записи Steam никогда не изменяются и не удаляются.
- **Интерфейс на русском и английском языках**, выбор зависит от языка клиента Steam.

## Установка

1. Загрузите `deck-clip-export.zip` из [последнего релиза](../../releases/latest).
2. В Decky откройте «Настройки» → General и включите **Developer mode**.
3. Откройте «Настройки» → Developer → **Install Plugin from ZIP** и выберите загруженный файл.

## Первоначальная настройка

Откройте меню быстрого доступа → Decky → Deck Clip Export → **Настройка**.

1. **ffmpeg.** Нажмите «Установить», если ffmpeg не найден (около 30 МБ). Если ffmpeg уже есть в системе, действий не требуется.
2. **LocalSend.** Установите [LocalSend](https://localsend.org) на устройство, которое будет получать файлы. Приложение бесплатно и доступно для Android, iPhone и iPad, Windows, macOS и Linux. Откройте его, убедитесь, что оба устройства подключены к одной сети, и нажмите **«Найти»** на экране настройки.
3. **Syncthing (дополнительно).** Нажмите **«Включить»** на карточке Syncthing, затем **«Установить»**, если Syncthing не найден (около 12 МБ). Если Syncthing уже установлен, плагин использует существующую установку. Установите Syncthing на устройство-получатель (Syncthing-Fork для Android, Möbius Sync для iPhone и iPad или Syncthing для компьютера), добавьте в приложении новое устройство и отсканируйте QR-код с экрана настройки. Когда появится запрос на подключение, нажмите **«Одобрить»**, затем примите папку «Deck Clip Export» на устройстве-получателе.

В LocalSend по умолчанию каждую передачу нужно подтвердить на устройстве-получателе. Чтобы принимать файлы без подтверждения, включите в LocalSend функцию **Quick Save** («Быстрое сохранение»).

В Syncthing оставьте на устройстве-получателе тип папки по умолчанию: **«Отправка и получение»**. На смартфоне рекомендуется разместить папку в `DCIM`, чтобы полученные файлы отображались в галерее. Тип **«Только получение»** не рекомендуется: при нём удалённые копии считаются локальными изменениями, а кнопка **«Откатить локальные изменения»** удаляет эти файлы с устройства-получателя.

## Отправка файлов

Нажмите Y на плитке, выберите **«Отправить»** в окне просмотра или выделите несколько файлов кнопкой X и нажмите Y либо **«Отправить»** на верхней панели. В окне отправки доступны:

- **Syncthing**: синхронизируемая папка (если Syncthing включён и настроен);
- **LocalSend**: устройства, найденные в сети; последнее использованное устройство указано первым.

Записи перед отправкой автоматически сохраняются в MP4. Ход передачи отображается на плитках, по завершении или при ошибке выводится уведомление.

Если устройство LocalSend требует PIN-код, введите его в окне отправки до выбора устройства. Если устройство не находится автоматически, введите его адрес (он отображается в LocalSend на вкладке «Получить») и нажмите **«Подключить»**.

### Точка доступа смартфона

На некоторых смартфонах в режиме точки доступа автоматическое обнаружение не работает. Если портативное устройство подключено к точке доступа смартфона и смартфон не находится, введите его адрес вручную. Обычно это адрес шлюза, который указан на экране настройки.

## Управление

| Кнопка | Действие |
| --- | --- |
| A | Открыть окно просмотра (превью, экспорт, отправка, удаление копий) |
| X | Выделить или снять выделение для групповых действий |
| Y | Отправить (выделенные файлы, если они есть) |
| Меню (≡) | Удалить копии |

В первой строке верхней панели расположены фильтры, переключатель вида (по дням или сетка) и управление размером плиток (− / +). Во второй строке находятся действия с выделенными файлами и команда **«Удалить все копии»**.

## Управление хранилищем

Плагин создаёт собственные файлы: экспортированный MP4 записи и, при отправке через Syncthing, копию для отправки в синхронизируемой папке. Копия для отправки является жёсткой ссылкой и не занимает дополнительного места, пока существует файл MP4; копия скриншота является жёсткой ссылкой на файл Steam. Команда **«Удалить копии»** удаляет эти файлы. Скриншоты и записи Steam всегда сохраняются, а копии можно создать повторно в любой момент. Уже отправленные файлы хранятся на устройствах-получателях независимо и не затрагиваются.

По умолчанию Syncthing распространяет удаление файлов на все подключённые устройства. Чтобы этого избежать, плагин сначала добавляет копию для отправки в список исключений Syncthing на портативном устройстве (строки с пометкой «Deck Clip Export» в файле `.stignore` папки), дожидается подтверждения от Syncthing и только после этого удаляет файл. Не удаляйте эти строки из `.stignore`. Если Syncthing не запущен, удаление отменяется. Файл, отправленный повторно, получает имя с номером, например `…_2.mp4`, поскольку прежнее имя остаётся исключённым из синхронизации.

**«Удалять копии после отправки»** (меню быстрого доступа, по умолчанию выключено):

- LocalSend: файл MP4 удаляется сразу после отправки;
- Syncthing: каждые 20 секунд плагин проверяет, какие отправленные файлы полностью получены другим устройством, и удаляет их копии.

## Параметры

В меню быстрого доступа доступны следующие параметры:

- отправка через Syncthing, папка для отправки (по умолчанию `~/Sync/Deck Clip Export`) и распределение по папкам игр;
- автоматическое удаление копий после отправки;
- вид галереи и размер плиток;
- папка для экспорта MP4 (по умолчанию `~/Videos/Steam Recordings`);
- дополнительные папки записей, если Steam записывает на другой накопитель.

## Совместимость

Плагин предназначен для любых систем x86_64, на которых Decky Loader работает в игровом режиме Steam, включая Steam Deck (SteamOS), Bazzite и ChimeraOS. Разработка и проверка выполнялись на GPD Win Mini под управлением Bazzite. Поддерживаются также установки Steam через Flatpak.

Плагин реализует отправляющую сторону протокола LocalSend версии 2, включая клиентский сертификат, который требуется начиная с LocalSend 1.18, и работает с официальными приложениями LocalSend. Приём файлов не поддерживается.

## Расположение файлов

| Содержимое | Расположение |
| --- | --- |
| Параметры плагина, сохранённые устройства LocalSend, конфигурация установленного плагином Syncthing | `~/homebrew/settings/deck-clip-export/` |
| Загруженные ffmpeg и Syncthing, кэш превью | `~/homebrew/data/deck-clip-export/` |
| Журналы | `~/homebrew/logs/deck-clip-export/` |
| Веб-интерфейс Syncthing, установленного плагином | `http://127.0.0.1:8384` (или следующий свободный порт) |

Syncthing, установленный плагином, работает, пока работает Decky и включена отправка через Syncthing. При её выключении он останавливается, а при удалении плагина останавливается и удаляется вместе с загруженными программами.

## Устранение неполадок

- **Галерея не загружается или показывает ошибку.** Проверьте журналы в папке, указанной выше.
- **Устройство LocalSend не находится.** Убедитесь, что на нём открыт LocalSend и оба устройства находятся в одной сети. Некоторые маршрутизаторы изолируют беспроводных клиентов друг от друга (гостевые сети, режим «AP isolation»); в этом случае устройства не могут связаться. Попробуйте ввести адрес вручную.
- **Передача через LocalSend не начинается.** Проверьте, не ожидает ли устройство-получатель подтверждения передачи. Если ответа нет в течение пяти минут, запрос отменяется.
- **«Syncthing установлен, но не запущен»** при отдельно установленном Syncthing. Запустите его, например командой `systemctl --user enable --now syncthing`.
- **Steam не завершает загрузку после перезапуска Decky.** Не перезапускайте Decky (`systemctl restart plugin_loader`) при запущенном Steam в режиме рабочего стола. Перезапускайте Decky из игрового режима или при закрытом Steam.

## Сборка из исходного кода

```
pnpm install
pnpm run build
```

Скопируйте `dist/`, `main.py`, `plugin.json`, `package.json` и `LICENSE` в `~/homebrew/plugins/deck-clip-export/` и перезапустите Decky. При публикации релиза на GitHub автоматически запускается сборка (GitHub Actions), которая прикрепляет к релизу архив для установки.

Серверная часть (`main.py`) намеренно использует только базовые модули Python, поскольку среда Python, входящая в состав Decky, не содержит полной стандартной библиотеки. Сетевые запросы к устройствам LocalSend выполняются через `curl`, клиентский сертификат LocalSend создаётся с помощью `openssl`.

## Стороннее программное обеспечение

Перечисленные ниже программы не входят в состав плагина. Они загружаются по запросу из официальных релизов на GitHub и проверяются по закреплённой контрольной сумме SHA-256.

- [Syncthing](https://github.com/syncthing/syncthing) v2.1.6, MPL-2.0
- [ffmpeg](https://ffmpeg.org) 7.0.2, статическая сборка John Van Sickle из [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static), GPL-3.0

Плагин не связан с проектами LocalSend и Syncthing.
